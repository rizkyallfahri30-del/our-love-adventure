OUR LOVE ADVENTURE — WEBSITE FLASK

CARA MENJALANKAN:
1. Ekstrak file ZIP.
2. Buka folder hasil ekstrak di VS Code.
3. Buka terminal di folder tersebut.
4. Jalankan: py -m venv .venv
5. Windows PowerShell: .venv\Scripts\Activate.ps1
   Jika perintah py tidak tersedia, gunakan python.
6. Jalankan: pip install -r requirements.txt
7. Jalankan: python app.py
8. Buka browser: http://127.0.0.1:5000

Game ini tidak membutuhkan foto atau file musik tambahan.
Internet hanya dibutuhkan untuk memuat font Google Fonts; tanpa internet
website tetap berjalan dengan font cadangan.

Untuk mengubah pesan akhir, edit bagian <article class="letter"> di
templates/game.html.
